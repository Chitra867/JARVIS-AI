# 🤖 JARVIS OS

**JARVIS OS** is a local AI-powered desktop assistant designed to combine conversational intelligence, persistent memory, voice interaction, wake-word detection, safe computer actions, and multi-step task execution in one system.

The project is inspired by the idea of a personal AI assistant while focusing on privacy, local execution, modular architecture, and safe automation.

---

## ✨ Current Features

- 💬 Conversational AI using a local Ollama model
- 🧠 Persistent long-term memory
- 🎙️ Voice command recognition
- 🗣️ Neural British voice output
- 👂 “Hey Jarvis” wake-word detection
- 🔄 Continuous hands-free conversation
- 🌐 Browser and web-search commands
- 🖥️ Application launching
- 🧩 Skill-based command architecture
- 📋 Multi-step task planning
- 🛡️ Safety validation before actions are executed
- ⚡ FastAPI backend
- 🎨 Futuristic React JARVIS HUD
